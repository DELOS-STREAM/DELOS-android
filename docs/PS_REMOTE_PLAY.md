# PlayStation Remote Play

## Purpose

DELOS's own implementation of the PlayStation Remote Play protocol (PS5 first, PS4 kept in the code), written from the
clean-room specification in [research/ps-remote-play-protocol.md](research/ps-remote-play-protocol.md). It lives on the branch
`feature/25-ps-remote-play` and is not merged to `main` until the whole feature is stable (owner, 2026-11-21).

## Scope

Covered: discovery, wake, PSN sign-in, registration with the console PIN, session init and ctrl, the Takion stream connection
with BIG/BANG and the stream keys, video reassembly with Reed-Solomon recovery, Opus audio, controller input, the shell UI
(prototype F in `build/ps-pairing-proto/`). Not covered yet: Senkusha (RTT/MTU measurement; the spec's fallback of MTU 1454
and RTT 1 ms is used), internet play, microphone, DualSense haptics and adaptive triggers, the stream menu and DELOS's video
path (upscalers, frame pacing) for PlayStation streams.

## Behavior

1. The console is found by the UDP search on 9302 (PS5) and 987 (PS4). The answer's `system-version` and protocol version
   select the target (`PsTarget`).
2. Registration, session init and ctrl use TCP/UDP 9295 whatever `host-request-port` reports (spec 5.9 (3); a PS5 on firmware
   14230000 reports 997).
3. Takion DATA and DATA_ACK chunks are authenticated with the GMAC but not encrypted; AV payloads, feedback and microphone
   packets are encrypted at key position + 16 (spec 5.9).
4. The PSN account id comes from Sony's sign-in page in a WebView (`PsOAuth`); it is kept for the next pairing.
5. The constants extracted from Sony's client ship in the app (owner, 2026-11-21: open source, not sold). `PsConstants.kt`
   is generated by `tools/ps/gen_constants.py`, which checks every table against the checksums of the constants document.
6. Start screen: the `PC | PlayStation` tab row in the status bar's line (the Settings tab component, L1 / R1 at its sides and
   on the controller) switches the mode. The PlayStation mode uses the blue theme (`playStationColors`) and its own animated
   background (`PlayStationBackground`: light ribbons and drifting face-button shapes), cross-faded with the user's background
   in 700 ms (instantly with reduced motion). The profile chip sits in the bottom-left corner in both modes; the DELOS logo
   stays top-left.
7. Pairing flow `Screen.PairPs`: Find (search, circles), Sign in, PIN (8-digit pad for the controller), Done (Play now or back
   to Start). A console circle starts `PsStreamActivity`: wake, ctrl retried while the console wakes, the stream, the hyperspace
   loader in blue until the first frame.

## Code map

| Path | Role |
|---|---|
| `ps/PsCrypto.kt` | Targets, RP crypt, session and registration key derivation |
| `ps/PsRegistration.kt` | Registration request and answer, account id |
| `ps/PsDiscovery.kt` | Search, answer parsing, wake |
| `ps/PsClients.kt` | Registration client, ctrl channel (session init, ctrl request, binary messages) |
| `ps/PsSession.kt` | Ctrl header values, DID, launch spec, BIG, secp256k1 ECDH |
| `ps/PsGkCrypt.kt` | Stream keystream and GMAC |
| `ps/PsTakionPackets.kt`, `ps/PsProto.kt` | Takion control packets and fragmentation, minimal protobuf |
| `ps/PsStream.kt` | Stream connection: handshake, reliable DATA, BIG/BANG, STREAMINFO, AV, heartbeats, congestion, input |
| `ps/PsVideo.kt`, `ps/PsFec.kt` | AV header parsing, frame reassembly, Reed-Solomon erasure decoding |
| `ps/PsFeedback.kt` | Controller state packet and button/touch events |
| `ps/PsAudioPlayer.kt`, `ps/PsOAuth.kt` | Opus playback with a jitter buffer; PSN sign-in |
| `shell/ps/PsShell.kt`, `shell/ps/PsScreens.kt` | Mode, blue theme, console store; mode switch, start content, pairing steps |
| `shell/ps/PsBackground.kt`, `shell/ps/PsStreamActivity.kt` | PlayStation background; the stream activity |
| `src/debug/.../ps/PsDebugActivity.kt` | Debug-build bench: search, register, wake, connect, HEVC on a SurfaceView |

## Verification

- `PsVectorsTest`: every test vector of the specification (key derivation, registration, ctrl headers, launch-spec
  keystream, ECDH, stream keys and GMACs, FEC, feedback, account id, wake credential, Takion INIT).
- `PsStreamPartsTest`: a real PS5 discovery answer, frame reassembly with a lost source unit recovered by FEC, loss
  ranges, fragmentation, protobuf round trip.
- Bench on the device: `adb shell am start -n io.github.meitoncz.delos.debug/com.limelight.ps.PsDebugActivity`.

### Not verified

- The stream against wired Ethernet; right stick, triggers, touchpad; HDR; haptics.
- `PsStreamActivity` launched from the shell against the console (the bench path is verified).

status 200, firmware 14230000, target PS5 1.0).
